# 续言 Continuum

> 让故事接续、延续下去 —— 面向中文网络文学作家的开源桌面写作助手

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Version](https://img.shields.io/badge/version-0.1.0-2D7FF9)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)
[English](./README_EN.md)

**续言 / Continuum** 是一款开源的中文网文写作助手。它把创作数据完全保存在本地、通过统一的 AI 适配层接入任意 OpenAI 兼容模型，帮助网络文学作家更高效地完成长篇连载创作。

- **数据自主**：作品与正文以纯 Markdown 保存在本地，永远属于作者自己，无平台锁定
- **AI 自备**：使用你自己的 API Key 直连任意 OpenAI 兼容服务（DeepSeek / OpenAI / 硅基流动 / Ollama），成本透明可控
- **创作友好**：Tiptap 块级编辑器 + 大纲导航 + 三模式写作界面，贴合长篇创作流程
- **知识增强**：本地 BM25 + 可选 Embedding 的混合语义检索，AI 对话自动注入作品知识上下文
- **开源开放**：MIT 协议，可自由使用、修改与二次开发

## 功能特性

### ✍️ 编辑器

- **块级富文本**：基于 Tiptap（ProseMirror），原生支持标题、表格、任务列表、代码块、引用、图片、链接等
- **三种模式**：编辑（单栏 Markdown 实时渲染预览）/ 预览 / Markdown 源码，右下角一键切换
- **格式工具栏**：加粗 / 斜体 / 删除线 / H1–H3 / 引用 / 有序与无序列表 / 任务列表 / 表格 / 链接 / 图片 / 代码块 / 分隔线 / 撤销重做
- **纸稿排版**：思源宋体衬线正文、行距 1.9、首行缩进，贴合中文阅读习惯
- **实时统计与自动保存**：实时中文字数；输入防抖 800ms 自动保存，Ctrl+S 立即落盘
- **章节标题块**：打开章节自动在正文开头插入章节名（默认文本块，可编辑），重命名章节时标题块自动同步
- **伏笔 / 时间标注联动**：选中文本即可「创建伏笔」；正文高亮标注（伏笔状态色 / 时间线紫色），点击标注双向定位侧栏对应条目（收起态自动展开）

### 📚 创作管理

- **作品 / 章节树**：多作品并行，搜索过滤、双击重命名、一键删除
- **大纲自动提取**：从正文标题自动生成可点击跳转的大纲
- **欢迎页**：无作品时提供「新建 / 导入 / 示例」三入口，示例一键生成演示章节
- **创作知识库**：侧栏 角色 / 设定 / 伏笔 / 素材 四 Tab，结构化记录人物卡、世界观、剧情伏笔与灵感素材，全部纳入语义检索范围
- **卷层级管理**：作品 → 卷 → 章节三级结构，卷支持新增 / 重命名 / 删除 / 排序，章节一键归属卷
- **时间线模块**：侧栏「时间线」Tab 记录剧情时间节点（可编辑时间 + 剧情梗概），增删改 / 排序 / 实时保存，正文时间标注与条目双向联动
- **全局全文搜索**：Ctrl+Shift+F 跨全部作品检索章节正文与创作知识，结果一键跳转
- **历史版本管理**：Ctrl+S 手动保存自动生成章节快照（每章保留 50 份），可预览与恢复

### 📥 导入 / 导出

- **Markdown 导入**：作为新作品（+ 第一章）或追加为当前作品的新章节
- **导出**：章节 ×（Markdown / TXT）；作品 ×（Markdown / TXT / **PDF** / **EPUB** / **DOCX**）——PDF 经 printToPDF 排版，EPUB3 标准结构，DOCX 支持标题/列表层级
- **存储引擎**：默认 JSON + Markdown 文件存储；设置环境变量 `CONTINUUM_STORAGE=sqlite` 可切换 SQLite（sql.js 零原生依赖）引擎，接口一致、数据无缝替换

### 🤖 AI 助手

- **统一适配层**：任意 OpenAI 兼容接口，三段式配置（API Key / Base URL / 模型）+ 温度调节 + 连接校验 + 可选 Embedding 模型
- **流式对话**：AI 面板四 Tab（对话 / 润色 / 续写 / 知识库），可「附带上文」（当前章节）与「注入知识库」（RAG 参考片段）让回答贴合语境，两者默认开启
- **选区润色 / 光标续写**：保持情节与设定不变地优化文笔；按前文风格自然续写，结果一键写回正文（Ctrl+R / Ctrl+Enter）
- **语义检索**：本地 BM25（中文 n-gram）离线可用；配置 Embedding 模型后自动升级为 BM25 + 向量 50/50 加权融合，失败自动降级

### 🎨 体验与辅助

- **五套主题**：浅色 / 深色 / 护眼浅（米黄纸稿）/ 护眼深 / 高对比，Ctrl+Alt+T 循环切换并持久化
- **命令面板**（Ctrl+K）：聚合常用动作的模糊搜索面板
- **通知中心 / Toast**：全局轻提示 + 铃铛通知历史
- **沉浸模式**（F11）：隐藏一切干扰，专注写作
- **窗口状态持久化**：窗口几何、主题、折叠状态重启后恢复
- **辅助工具**：全局热键 Ctrl+G 唤起窗口、跨窗口文本录入（快/慢节奏）、剪贴板监听与历史一键插入、窗口置顶

## 快速开始

### 环境要求

- Node.js ≥ 18
- npm ≥ 9

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/RuanCH0924/continuum.git
cd continuum/desktop

# 安装依赖
npm install

# 启动开发模式（Electron + HMR）
npm run dev
```

**Windows 用户**：也可以直接双击根目录的 [`start_continuum.bat`](./start_continuum.bat) 一键启动（自动检测 Node.js、首次自动安装依赖）。

> 国内网络环境如果安装 Electron 二进制超时，可配置 npm 镜像后重试：`npm config set registry https://registry.npmmirror.com`。

### 验证

```bash
npm run typecheck   # TypeScript 类型检查（主进程 + 渲染进程）
npm test            # Vitest 单元测试（91 项 / 14 个测试文件，全量通过）
npm run build       # 生产构建（out/ 产物）
```

> 测试覆盖：存储 CRUD、Markdown 往返与大纲、AI 流式客户端、快捷键与主题、跨窗口录入核心、
> 写作统计、导入导出、BM25 检索、知识注入上下文。详细报告见 [docs/项目设计文档.md](./docs/项目设计文档.md#8-测试与验证报告)。

## AI 服务配置

1. 点击顶栏「设置」或 AI 面板齿轮，打开 **AI 服务设置**；
2. 选择服务商预设（DeepSeek / OpenAI / 硅基流动 / Ollama），或自定义 Base URL；
3. 填入你的 API Key（Ollama 等本地服务无需 Key），选择模型并调节温度；
4. （可选）填写 **Embedding 模型**（如 `bge-large-zh` / `text-embedding-ada-002`）启用知识库语义增强，留空则知识库仅关键词检索；
5. 点击「校验连接」确认配置可用后保存（配置仅保存在本地 `data/settings.json`）。

> AI 对话页勾选「注入知识库」后，每次提问会自动检索当前作品的正文与创作知识，
> 以参考片段形式注入提示词（检索失败自动跳过，不影响对话）。

## 数据存储

所有数据保存在 `desktop/data/` 目录，正文为**纯 Markdown**，可直接用任意文本编辑器打开：

```
data/
├── settings.json                     # 全局设置（主题 / AI 配置 / 统计 / 窗口状态）
└── works/
    └── <workId>/
        ├── meta.json                 # 作品元数据
        ├── notes.json                # 创作知识（角色 / 设定 / 伏笔 / 素材）
        ├── volumes.json              # 卷容器（章节层级分组，含章节关联）
        ├── timeline.json             # 时间线条目（时间描述 + 剧情梗概）
        ├── embeddings.json           # Embedding 向量缓存（可删除，自动重建）
        └── chapters/
            ├── index.json            # 章节标题索引
            └── 001_章节名.md          # 章节正文（纯 Markdown）
```
