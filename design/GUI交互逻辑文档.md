## 1. 交互总则

| 原则 | 说明 |
| --- | --- |
| **零打断** | 保存、字数刷新、自动完成一律静默反馈（状态栏 / Toast），绝不弹窗打断输入流 |
| **选区即上下文** | 选中正文是触发 AI 功能的核心上下文，所有 AI 功能优先消费当前选区 |
| **所见可逆** | 任何 AI 写入前提供 Diff 预览；一切破坏性操作提供确认或撤销 |
| **按需呈现** | 面板默认折叠，功能入口遵循「快捷键 > 命令面板 > 右键菜单 > 显式按钮」降序 |
| **状态可见** | 长任务必须显示进度且可取消；失败必须给出原因与修复路径 |

## 2. 全链路创作流程

```
┌─────────┐   ┌───────────┐   ┌───────────┐   ┌──────────────┐   ┌───────────┐
│ 启动应用 │ → │ 选择/新建  │ → │ 章节码字   │ → │ 辅助调用      │ → │ 校对 / 导出│
└─────────┘   └───────────┘   └───────────┘   └──────────────┘   └───────────┘
   │主题恢复      │空状态引导    │自动保存      │AI 流式反馈      │多格式导出
   │窗口恢复      │模板选择      │字数+动效     │可中断可重试      │版本回溯
   │最近作品      │导入向导      │目标进度      │上下文注入        │通知中心回执
```

**主链路**：新建作品（向导）→ 自动建卷建章 → 码字（自动保存 + 字数动效）→ 选区 AI 润色（Diff 确认）→ 校对 → 导出。全程平均操作步数目标 ≤ 15 步。

## 3. 模块交互细则

### 3.1 启动与空状态

**首次启动（无作品）**：

1. 中央编辑区整屏显示「欢迎卡」（`design/GUI高保真原型.html` 演示区「① 空状态」可预览）：
   - 左：品牌插画卡（LOGO + 品牌语 + 特性三行）；
   - 右：三个入口卡片 —— **创建新作品**（主）、**导入 Markdown / TXT**（次）、**浏览示例《雪山隐狐》**（次）；
   - 底部小字：「数据仅存储在本地 · 所有 AI 调用走你的 API Key · 无需注册」；
2. 侧栏显示空状态：「还没有作品，点击下方新建」+ Ghost 虚线按钮；
3. 首次启动附加 FTUE 引导（3 步浮层，见 §3.11）。

**非首次启动**：恢复上次作品 / 章节 / 编辑模式 / 主题 / 窗口状态（`config/window_state.json`）。

**首页（数据仪表台，启动默认）**：

1. 中央区域显示「首页」：顶部问候 + 数据统计模块 + 作品展览模块（`components/home/HomePage.tsx`）；
2. 无作品时首页显示书架空态（新建 / 导入 / 示例三入口，与欢迎页一致）；
3. 作品展览：卡片化展示（渐变封面题词 / 标题 / 题材 / 简介摘要 / 创建时间），支持关键词搜索、题材分类筛选（chips，再次点击取消）、分页加载（每页 8 张，页码窗口折叠省略号）；PC hover 卡片上浮 + 封面微放大 + 阴影加深，触屏按压缩放反馈（`touch-action: manipulation` 防双击缩放）；点击卡片 → `selectWork` 进入作品详情（编辑器）；
4. 数据统计：指标卡（作品总数 / 累计总字数 / 今日字数 / 周期字数）数字滚动过渡；周 / 月 / 年切换写作量柱状图，hover / 触按高亮 + 数值浮层，周期切换重绘生长动效，数据更新高度平滑过渡；
5. 导航：顶栏「首页」常驻按钮（当前态高亮）与面包屑「我的书架」均可返回首页；侧栏点击作品 / 章节自动切回编辑器。

### 3.2 顶栏与面包屑

**顶栏（42px）**：品牌（LOGO + 名）| 文件 编辑 视图 插入 AI 工具 设置 | 全局工具（搜索 / 主题 / 命令 / 铃铛 / 沉浸 / 帮助）。

| 按钮 | 触发 | 行为 |
| --- | --- | --- |
| 搜索 | 点击 / Ctrl+Shift+F | 打开全局搜索（Top 下拉 + 全文搜索入口） |
| 主题 | 点击 / Ctrl+Alt+T | 循环切换 浅色 → 深色 → 护眼浅 → 护眼深 → 高对比；Toast 反馈 |
| 命令 | 点击 / Ctrl+K | 命令面板（§3.7） |
| 铃铛 | 点击 / Ctrl+Shift+N | 通知中心抽屉（§3.8）；有未读时显示红色角标数字 |
| 沉浸 | 点击 / F11 | 沉浸模式（§3.10） |
| 帮助 | 点击 / F1 | 内置帮助中心（快捷键速查卡 §3.11） |

**面包屑（34px）**：`我的书架 ▸ 作品 ▸ 卷 ▸ 当前章节`（当前章节加粗）；右侧「✓ 已保存 HH:MM:SS」+「今日 +N 字」。保存成功时 ✓ 闪动 500ms（不弹窗）。

### 3.3 左侧内容管理

**结构**：`[作品] [大纲] [角色] [设定] [伏笔] [素材]` 六 Tab + 搜索框 + 内容区。

**Tab 切换**：点击 Tab 头部切换（原型已实现）；双击 Tab 头部区域整体折叠侧栏为 48px 图标条（rail），rail 图标点击展开并直达对应 Tab。

**作品 Tab**：

| 操作 | 交互 |
| --- | --- |
| 展开/折叠卷或作品 | 点击 chevron（旋转动画 200ms） |
| 切换作品 / 章节 | 点击节点 → 加载章节；当前章节高亮品牌色底 |
| 新建作品 | 顶部/空状态「+ 新建作品」→ 新建向导（§3.9） |
| 新建章节 | 右键章节所在作品 → 新建章节；或 Ctrl+Shift+N |
| 重命名 | 双击节点文字 → 行内编辑（Enter 确认 / Esc 取消） |
| 删除 | 右键 → 删除（二次确认弹窗，明确「此操作不可恢复」） |
| 排序 | 拖拽卷/章节节点（自动落位保存） |
| 状态标记 | 章节右侧 tag（连载中 / 存稿 / 关键 / 伏笔） |

**大纲 Tab**：树形展示正文标题自动提取 + 手动节点；点击跳转编辑区对应段落（`outline_activated` 沿用现有信号语义）；拖拽调整层级。

**角色 Tab**：角色卡列表（头像 + 姓名 + 一句话简介）；点击展开角色卡详情（结构化字段 + 自由文本 + AI 一键补全）；卡片 hover 边框变品牌色。

**设定 / 伏笔 / 素材 Tab**：树 / 状态列表 / 素材网格；伏笔卡片左侧状态色条（待回收=黄 / 进行中=蓝 / 已回收=绿）；素材空状态引导拖拽导入。

**搜索框**：输入即检索（300ms debounce），命中 作品名/章节/大纲/角色/伏笔；底部下拉提供「全文搜索（Ctrl+Shift+F）」入口。

### 3.4 中央编辑器

**三态模式（2026-08-14 调整）**：仅编辑（单栏 Markdown 实时渲染，所见即所得）/ 仅预览 / Markdown 源码（工具栏右侧胶囊切换，快捷键 Ctrl+\）。原「双栏」模式已按产品决策移除，不再支持编辑与预览并排。

**格式工具栏（40px）**：加粗 / 斜体 / 下划线 ｜ H1-H3 ｜ 引用 / 无序 / 有序 / 任务 / 表格 / 链接 / 图片 / 代码 ｜ 撤销 / 重做。

**码字交互**：

1. 编辑区聚焦 → 工具栏自动降透明，鼠标移出 3s 后隐藏（沉浸内完全隐藏）；
2. 字数变化 → 状态栏字数数字微动效（+N 飞入 500ms 淡出）；
3. 自动保存（默认 30s）→ 面包屑 ✓ 闪动 + 状态栏时间刷新；
4. 打字机模式（设置可选）：光标始终垂直居中；
5. 滚动条自动隐藏（设置可选）：仅滚动时短暂出现。

**选区上下文**：选中正文后，编辑区出现悬浮操作条（淡出淡入），提供 润色 / 改写 / 续写 / 翻译 / 总结 五项。

### 3.5 右侧 AI 助手

**结构**：`[对话] [润色] [续写] [知识库]` 四 Tab + 顶部配置行（模型 / 注入上下文 / 设置）+ 对话流 + 输入区。

**配置行**：模型下拉（DeepSeek / OpenAI / 硅基流动 / Ollama，读 ProviderRegistry）；上下文注入下拉（当前章节 / 角色卡 / 大纲）；配置变更即时生效并 Toast 确认。

**对话 Tab（默认）**：流式气泡；AI 气泡底部操作行 = 插入到光标 / 复制 / 朗读 / 重新生成；生成中显示三点脉动动画 + 按钮变「取消」。

**润色 / 改写 Tab**：显示「选区摘要（字数 / 可优化点）」，生成后提供 **查看 Diff 对比**（微浮窗，见 §3.9）；操作后回写正文。

**续写 Tab**：设置续写起点（光标/选区/章节尾）+ 风格 + 长度；完成后以**灰色预览**插入编辑区光标处，浮出提示「Tab 接受 · Esc 取消 · Shift+Tab 替换选区」。

**知识库 Tab**：语义检索框 + 卡片结果（标题 + 出处 + 片段高亮 + 匹配分 + 关联线索），点击跳转正文位置；匹配分 ≥ 90 用绿色、70–89 用中性、<70 提示低置信。

**快捷键**：Ctrl+Shift+A 展开/收起 AI 面板；Ctrl+R 润色选区；Ctrl+J 改写；Ctrl+Enter 续写；Ctrl+Shift+K 知识库检索。

**上下文注入说明（透明 AI）**：每次请求右侧显示「已注入上下文：当前章节 + 角色卡 ×2」，让作者明确 AI 基于哪些材料作答（差异化于腾讯的 AI 黑盒）。

### 3.6 底部状态栏

30px 高度，两组信息：

| 左半 | 右半 |
| --- | --- |
| 字数 / 字符 | 自动保存时间 |
| 今日 +N（绿色正数） | UTF-8 |
| 目标进度（进度条 + 百分比，5 分钟刷新） | MD · GFM |
| 模型名 | v1.0 · 数据本地 |

目标完成（≥100%）时进度条变绿 + 通知中心推送一条「今日目标达成」鼓励。

### 3.7 命令面板

**召唤**：Ctrl+K（macOS Cmd+K）、顶栏命令按钮。

**交互**：

| 行为 | 规则 |
| --- | --- |
| 打开 | 焦点移入输入框，默认选中上次使用的命令（最近使用置顶 5 条） |
| 过滤 | 输入即模糊匹配「命令名 + 快捷键 + 关键字」（不区分大小写） |
| 选择 | ↑↓ 移动高亮、Enter 执行；鼠标点击亦可 |
| 关闭 | Esc / 点击遮罩 / 执行后自动关闭，焦点归还触发点 |
| 空结果 | 显示「无匹配命令」+ 「自定义命令」入口（可把常用 AI 提示词存为命令） |

### 3.8 通知中心与 Toast

**通知中心**（顶栏铃铛 + Ctrl+Shift+N）：

- 抽屉 340px 右上滑出，时间倒序；四类角标（信息蓝 / 成功绿 / 警告黄 / 错误红）；
- 每条通知：标题 + 详情 + 操作按钮（查看版本 / 立即重建 / 撤销 / 复制详情 等，按类型）；
- 「全部清除」一键清空；有未读时顶栏铃铛红点角标。

**Toast**：顶部居中，3s 自动消失；分类色；最多 3 条并存。用于轻量结果反馈（保存成功 / 主题切换 / 配置已保存）。

### 3.9 弹窗体系

| 弹窗 | 触发 | 结构 | 关闭 |
| --- | --- | --- | --- |
| 新建作品向导 | 欢迎卡 / 侧栏 / Ctrl+N | 作品名* / 副标题 / 题材 / 篇幅 / 目标字数 / 简介 / 默认卷名 / 「立即建第一章」勾选 | 取消 / 创建；必填项为空时创建按钮禁用 |
| 导入向导 | 欢迎卡 / 文件菜单 | 选择文件（Markdown/TXT 多选）→ 映射章节 → 预览 | 取消 / 导入（进度 + 可取消） |
| 导出向导 | Ctrl+Shift+E | 格式（MD/HTML/PDF/EPUB/TXT）× 范围（章/卷/全书）× 选项（大纲批注/AI 摘要/水印）→ 路径 | 取消 / 导出（进度条） |
| 格式设置 | 视图菜单 / Ctrl+K → format | 主题 / 字体 / 字号 / 行距 / 缩进 / 自动保存 / 打字机 / 行号 / MD 标记 / 大纲提取 | 恢复默认 / 应用 |
| 设置中心 | 设置菜单 / Ctrl+, | 左侧导航 通用·外观·编辑器·AI·热键·数据·高级；右侧表单；变更实时生效 | 关闭 / 恢复默认 |
| **AI Diff 微浮窗** | 润色/改写完成 | 左：原文（灰底+红删除线）右：润色稿（绿底+下划线新增）＋ 字数变化；底部 全部替换 / 仅替换选中 / 取消 | 非模态，贴选区下方（原型演示 ⑤） |
| 删除确认 | 删除作品/章节 | 二次确认 + 「此操作不可恢复」警示文案 | 确认 / 取消 |

**弹窗规范**：模态弹窗带 overlay 遮罩 + focus trap；非模态浮层（Diff / 通知）无遮罩、可多开（浮层互不阻塞）。

### 3.10 沉浸模式

**进入**：F11 / 顶栏沉浸按钮。

- 隐藏：顶栏、面包屑、格式工具栏、侧栏、AI 面板、状态栏；
- 保留：编辑区（最大化）+ 顶部悬浮工具条（鼠标悬停顶部 100px 时滑出，含：返回/主题/字数/目标进度/退出）；
- 编辑区行距与字间距放大 10%；
- **强制码字变体**（工具菜单「强制码字」）：设定本次目标字数与允许离开次数，进度未达标时顶部常驻小条，点「锁定」后隐藏侧栏不可恢复直到达标；
- 退出：F11 / 悬浮条按钮；自动恢复进入前的布局状态。

### 3.11 引导与帮助

| 能力 | 触发 | 内容 |
| --- | --- | --- |
| FTUE 引导 | 首次启动 | 3 步浮层：创建作品 → 写一段 → AI 润色；每步底部进度点；可跳过 |
| 场景气泡 | 新控件首次出现 | 3s 自动消失或用户操作后消失 |
| 快捷键速查卡 | Ctrl+/ / F1 | 分类速查表（§6 全图谱），支持搜索与点击模拟（原型「快捷键 Ctrl+/」演示） |
| 帮助中心 | F1（无速查时） | Markdown 渲染帮助文档 |

## 4. 状态与反馈规范

| 场景 | 反馈 | 层级 |
| --- | --- | --- |
| 保存成功 / 自动保存 | 面包屑 ✓ 闪动 + 状态栏时间 | 静默 |
| 字数变化 | 状态栏数字飞入动效 | 静默 |
| 主题切换 | Toast「已切换至深色主题」 | 轻量 |
| 命令执行成功 | Toast「已执行命令」 | 轻量 |
| AI 生成中 | 生成中动画 + 「取消」按钮 + 流式增量渲染 | 过程可见 |
| AI 生成完成 | 气泡 + 操作行 +（写入时 Diff 预览） | 结果可见 |
| 目标达成 | 进度条变绿 + 通知中心鼓励推送 | 通知 |
| 配置已保存 | Toast「配置已保存」 | 轻量 |
| 模型切换 | Toast + 状态栏模型名刷新 | 轻量 |

**三线反馈体系**：状态栏（持久信息）< Toast（短暂确认）< 通知中心（需要回执/可撤销的完整事件）。

## 5. 异常处理矩阵

| 异常 | 用户感知 | 反馈与出路 |
| --- | --- | --- |
| 未配置 API Key | 发起 AI 操作时 | Toast 错误「请先在设置 → AI 中配置 API Key」+ 通知中心错误条目 + 按钮「打开设置」跳转 |
| API Key 失效（401） | AI 请求失败 | 错误气泡内展示原因 401，操作行提供「重新配置」直达设置 |
| 网络超时 / 断网 | AI 请求失败 | 错误气泡 + 通知中心错误条目 + 「重试」按钮（重试前自动校验配置） |
| 余额不足（429/402） | AI 请求失败 | 错误气泡展示「额度不足」，操作行提供「更换模型」下拉 |
| 磁盘写入失败 | 自动保存失败 | 通知中心红色条目「保存失败：路径不可写」，提供「选择新位置」；不丢失编辑区内容（保留内存态） |
| 知识库索引过期 | 检索结果陈旧 | 通知中心警告条目「索引过期，需要重建（约 3 秒）」+「立即重建」 |
| 大章节切换 | 加载耗时 | 侧栏节点加载态（旋转小图标）；无阻塞弹窗 |
| AI 清空对话 | 误操作风险 | 二次确认（「确定清空当前对话？」） |
| 删除作品/章节 | 数据风险 | 二次确认 + 不可恢复警示 |
| 续写预览取消 | Esc | 灰稿移除，光标位置不变 |

**错误呈现规范**：错误文案必须包含「发生了什么 + 为什么 + 怎么解决」三要素；所有 AI 错误进入通知中心（红色），避免只闪一下 Toast 被忽略。
