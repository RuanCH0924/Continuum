# 序章

一只蚂蚁疑惑地抬起头，刺眼的阳光毫无遮拦地洒在它身上。它生活在一片广袤无垠的草原上，在它的认知里，世界就是脚下这望不到尽头的平面，只有前后左右。它是这个二维世界里忙碌的居民，每日穿梭在草丛间，奔波于寻找食物与建造巢穴，简单而重复地度过每一天。

平静的日子，却被一场突如其来的暴雨彻底打乱。豆大的雨点疯狂砸下，雨水迅速汇聚成汹涌的洪流，像一头失控的猛兽，瞬间冲垮了它那温馨的家园，将它卷入湍急的水流之中。它在生死边缘拼命挣扎，小小的身躯被水流无情地抛来抛去，给它的唯一选择是挣扎。

在它几乎要放弃的时候，水流将它冲到了一个前所未见的巨大生物前——一棵参天大树。这是它第一次使劲地抬起头观察。出于求生的本能，它开始攀爬这棵大树。每艰难地向上迈出一步，都是在踏入了一个全新的世界。这里有宽大的叶片，可以为它遮风挡雨；还有从未见过的美味蚜虫，散发着诱人的气息。它惊喜得浑身颤抖，这才意识到，原来自己一直生活的草原世界之上，还有如此广阔奇妙的天地。

可这个新世界，远没有想象中那么容易掌控。一阵狂风呼啸而过，就能轻松地将它从高高的枝头吹落，让它重重地摔回那熟悉的二维平面。但它没有放弃，它开始呼唤同伴，结队成行。一代又一代的蚂蚁，心中都怀揣着对高处世界的向往，它们不断摸索，寻找稳固的爬行路线，努力适应不同的树皮纹理。在一次次的跌倒与爬起中，终于在向上的世界里建立了新的族群，储存了足够过冬的食物。

大自然总是充满了惊喜，她孕育出一只与众不同的蚂蚁诞生了。在一次意外中，它借助一片被风吹落的树叶，在空中短暂地滑翔。那一瞬间，风声呼啸，俯瞰大地的新奇感让蚂蚁又开始了漫长而艰难的尝试。

一次又一次地从高处跃下，一次次失败，一次次牺牲，但它们从未退缩。它们不断调整姿势，学习借助风力。终于，它们能够在天空中自由地短暂飞行，征服草原之上的空间，俯瞰大地河川。而草原上忙碌的蚂蚁族群，未曾抬过头。

这诠释了进化。

一位大学老师的学科公开课演讲进行到这里结束了。台下没有雷动的掌声，取而代之的是一片纷纷扬扬的议论声。

“赵老师，那您认为人类的进化下一步会走向何方呢？”一名坐在台下听讲的大学新生高高举起了手，向台上的老师发问。赵老师并未直接作答，只是抬起手，指了指自己的脑袋，说道：“从这里开始……”那学生一脸困惑，追问：“您是说，人类的脑子会越来越聪明吗？还是说，会变得越来越大？”话音刚落，台下的一百多位学生们哄堂大笑，笑声在报告厅里回荡。

赵老师摇摇头，解释道：“你还是没有理解我刚才讲的故事。进化，不单单是量的改变。第一只蚂蚁有意识地引领其他蚂蚁爬上树，发现了另一个全新的世界，随后不断适应并改造这个世界，这全部都构成了一个蚂蚁种群的进化。”

那学生依旧站在座位上，接着问道：“那您觉得，人类的大脑要如何开启新的……进化呢？”

赵老师坚定地解释道：“人之所以区别于其他生物，是因为人类已经具备了复杂的意识。在进化方面，人类与其他动物的不同之处在于，人类拥有主动进化的意识。只要人有这个想法，进化就会开始……只不过……当下的人类，不像那些蚂蚁，还没有找到那个适宜他们进化的世界。”

此话一出，台下的讨论声愈发嘈杂，坐在报告厅第一排的负责维持秩序的老师，不得不站起身来，转身看向后方，他用力拍了拍手，示意大家安静。随后，皱着眉头，狠狠瞪了一眼台上的赵老师。

然而，赵老师仿佛没有察觉到这一切，依旧沉浸在自己的讲解中：“海洋生物能够进化，是因为它们找到了陆地。同理，人类若要进化，必然要寻得新的栖息之地。就如同海洋生物被水所束缚，人类也被一样东西禁锢住了……那便是时间。”当他说出“时间”这两个字时，台下再次响起一阵又一阵的议论。

“这都讲的什么呀，这还是学科介绍吗？感觉完全偏离主题了。”一个学生小声嘀咕道。

“赵老师不是教物理的吗？怎么讲起这些奇奇怪怪的东西了。”另一个学生附和着。

“怪不得赵老师的研究项目会被撤掉，就这研究方向，能不被撤吗？”又一人小声议论着。

“是啊，听说他年年都评不上先进，就他这研究思路，评不上也正常。”

“这不是在误导我们这些刚考上大学的新生吗？”一名学生满脸不满地说道。

“老师！您讲的内容和达尔文的进化论、马克思的唯物主义都不一样，既不符合科学的进化理论，又背离了唯物主义思想。您这简直就是唯心主义，纯粹的空想派！”那名提问的学生对赵老师的解释满脸不屑，周围的其他学生也纷纷点头表示支持。这时，一个学生跟着起哄道：“对呀，我们来大学是为了学习建设祖国的本领，可不是来听您讲这些不切实际的东西的。”负责维持纪律的老师坐在台下，沉默不语，任由学生们对赵老师进行批判。

那一年是高考恢复的第三年，也是赵老师顶着巨大压力，最后一次在公开场合演说这个话题。
