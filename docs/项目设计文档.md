## 1. 项目概览

| 项 | 值 |
| --- | --- |
| 项目名称 | 续言 Continuum |
| 定位 | 面向中文网络文学作家的开源桌面写作助手 |
| 当前版本 | v0.1.0（`desktop/package.json`） |
| 开发阶段 | **M0–M7 全部完成**（验收通过，打包除外）+ 4 项验收后增量功能 |
| 技术栈 | Electron 31 + electron-vite + React 18 + TypeScript + Tiptap 3 + Tailwind CSS 3 + Zustand |
| 存储 | 本地 JSON + 纯 Markdown 文件系统（接口可替换 SQLite） |
| 协议 | MIT，© 2026 RuanCH0924 |

**核心原则**：

- **数据自主**：作品与正文以纯 Markdown 保存在本地，永远属于作者，无平台锁定；
- **AI 自备**：自带 API Key 直连任意 OpenAI 兼容服务（DeepSeek / OpenAI / 硅基流动 / Ollama），成本透明可控；
- **本地优先**：检索与全部业务逻辑离线可用，远程 Embedding 仅为可选增强；
- **零原生依赖**：跨窗口录入（PowerShell WScript.Shell）、AI 客户端（fetch + SSE）均无原生编译依赖。

## 3. 功能需求与实现清单

各模块统一按「需求背景 / 交互流程 / 原型说明 / 验收标准 / 实现状态」描述。

### 3.1 编辑器

- **需求背景**：长篇网文创作需要兼顾富文本排版与纯文本持久化，正文必须是作者可读、可迁移的格式。
- **交互流程**：打开章节 → Markdown 经 `markdown-it` 渲染进 Tiptap → 编辑（工具栏/快捷键）→ 防抖 800ms 自动保存或 Ctrl+S 立即保存 → `turndown` 序列化回 Markdown 落盘。
- **原型说明**：对应原型中央编辑区；正文思源宋体、行距 1.9、首行缩进 2em（纸稿排版）；右下角三模式切换胶囊（编辑 / 预览 / 源码，编辑区即 Markdown 实时渲染）。
- **验收标准**：标题/表格/任务列表/引用/代码块等结构 Markdown 往返不失真；中文字数实时准确；大纲按标题自动提取并可点击跳转。
- **实现状态**：✅ 已实现（[EditorArea.tsx](../desktop/src/renderer/src/components/EditorArea.tsx)、[markdown.ts](../desktop/src/renderer/src/lib/markdown.ts)、[EditorToolbar.tsx](../desktop/src/renderer/src/components/EditorToolbar.tsx)）。

### 3.2 创作管理（作品 / 章节 / 大纲 / 欢迎页）

- **需求背景**：多作品并行管理长篇连载，章节树 + 大纲导航是核心组织方式。
- **交互流程**：欢迎页「新建/导入/示例」→ 侧栏作品树（搜索过滤、单击切换、双击重命名、删除）→ 大纲 Tab 点击跳转对应标题。
- **原型说明**：对应原型「① 空状态」「左侧内容管理」；六 Tab（作品/大纲/角色/设定/伏笔/素材）。
- **验收标准**：作品按更新时间倒序；章节序号自动递增；删除级联清理文件；大纲跳过代码块内标题。
- **实现状态**：✅ 已实现（[Sidebar.tsx](../desktop/src/renderer/src/components/Sidebar.tsx)、[WelcomeView.tsx](../desktop/src/renderer/src/components/WelcomeView.tsx)、[store.ts](../desktop/src/main/services/store.ts)）。

### 3.3 创作知识数据模型（角色 / 设定 / 伏笔 / 素材）

- **需求背景**：RAG 检索与 AI 参考需要结构化创作知识（角色卡、世界观设定、伏笔、素材），独立于正文组织。
- **交互流程**：侧栏四 Tab（角色/设定/伏笔/素材）→「+ 新建」/ 点击条目 → 编辑弹窗（标题/标签/正文/关联章节）→ 保存至 `works/<id>/notes.json`。
- **原型说明**：对应原型「角色 Tab / 设定 / 伏笔 / 素材」；本阶段落地为通用实体（KIND 区分），结构化字段留待 P2 细化。
- **验收标准**：四类实体 CRUD；标签可检索；伏笔/素材可关联章节序号；删除确认。
- **实现状态**：✅ 已实现（[NoteEditorDialog.tsx](../desktop/src/renderer/src/components/NoteEditorDialog.tsx)、`Note`/`NoteKind` 类型）。

### 3.4 导入 / 导出

- **需求背景**：用户已积累的 Markdown 稿件需要迁移进系统；成稿需要输出为通用格式分发。
- **交互流程**：顶栏「文件」菜单 → 导入作品/导入章节（系统文件选择器）→ 导出章节/作品（Markdown 或 TXT 保存对话框）。
- **原型说明**：原型「文件」菜单的收口实现；欢迎页「导入作品」入口同源。
- **验收标准**：`.md/.markdown/.txt` 可导入为「新作品+第一章」或「当前作品新章节」；TXT 导出去除行首标记；作品级导出含书名与全部章节。
- **实现状态**：✅ 已实现（[files.ts](../desktop/src/main/ipc/files.ts)、[importers.ts](../desktop/src/renderer/src/lib/importers.ts)、[exporters.ts](../desktop/src/renderer/src/lib/exporters.ts)）。

### 3.5 AI 助手（对话 / 润色 / 续写 / 知识注入）

- **需求背景**：以统一 OpenAI 兼容适配层接入任意服务，提供「伴随式」写作辅助而非独立聊天。
- **交互流程**：
  - 对话：输入 → 可选「附带上文」（当前章节前 3000 字）→ 可选「注入知识库」（RAG 检索参考片段，默认开）→ 流式 SSE 输出 → 可中断；输入区上方常驻「透明 AI」注入说明徽标；
  - 选区工具（2026-08-14）：选中正文浮出**悬浮操作条**（润色 / 改写 / 翻译 / 总结 / 续写），结果在**对比浮窗**（原文 vs 结果并排）确认后一键写回；
  - 润色（Ctrl+R）/ 改写（Ctrl+J）/ 翻译（Ctrl+Shift+T）：选区 → 流式处理 → 对比浮窗 → 应用/取消；
  - 续写（Ctrl+Enter）：光标前文末 2000 字 → 流式续写 → 对比浮窗 → 插入光标处；
  - 对话气泡操作行：AI 回复下方提供「插入到光标 / 复制 / 重新生成」。
- **原型说明**：对应原型「右侧 AI 助手」四 Tab（对话/润色/续写/知识库）与系统提示词设计。
- **验收标准**：SSE 增量逐块渲染；缺少 Key 且非本地服务时给出明确错误；中止可恢复；润色不改情节、续写保持人称风格。
- **实现状态**：✅ 已实现（[aiStore.ts](../desktop/src/renderer/src/stores/aiStore.ts)、[openaiCompat.ts](../desktop/src/renderer/src/lib/ai/openaiCompat.ts)、[AIPanel.tsx](../desktop/src/renderer/src/components/AIPanel.tsx)）。

### 3.6 RAG 语义检索（本地 BM25 + 可选 Embedding）

- **需求背景**：作品正文与创作知识量级增长后，关键词匹配不足以支撑「语义相关」召回；同时必须保证离线可用。
- **交互流程**：设置页填写 Embedding 模型（可选）→ AI 面板「知识库」Tab 手动检索 / 对话自动注入时检索 → 命中按相关度降序展示（来源标签 + 标题 + 片段）。
- **原型说明**：对应原型「知识库 Tab」检索列表；检索范围覆盖章节正文分块 + 全部四类创作知识。
- **验收标准**：中文 n-gram + BM25 离线召回准确；配置 Embedding 后 50% 加权融合余弦相似度；Embedding 失败自动降级纯本地；向量缓存按 chunk 文本指纹失效重建。
- **实现状态**：✅ 已实现（[search-core.ts](../desktop/src/main/services/search-core.ts)、[embeddings.ts](../desktop/src/main/services/embeddings.ts)、[search.ts](../desktop/src/main/services/search.ts)、[retrieval.ts](../desktop/src/renderer/src/lib/retrieval.ts)）。

### 3.7 体验层（主题 / 命令面板 / 快捷键 / 沉浸 / Toast）

- **需求背景**：贴合写作习惯的视觉与操作效率，减少创作中断。
- **交互流程**：Ctrl+Alt+T 循环五主题（浅/深/护眼浅/护眼深/高对比）；Ctrl+K 命令面板；F11 沉浸模式；顶栏铃铛查看通知历史。
- **原型说明**：Design Tokens（Primitive → Semantic → Component）三层映射，见 [GUI设计规范.md](../design/GUI设计规范.md) §2。
- **验收标准**：主题切换即时且持久化；快捷键在输入态自动屏蔽（除显式允许项）；窗口几何/主题/折叠状态重启恢复。
- **实现状态**：✅ 已实现（[uiStore.ts](../desktop/src/renderer/src/stores/uiStore.ts)、[hotkeys.ts](../desktop/src/renderer/src/lib/hotkeys.ts)、[globals.css](../desktop/src/renderer/src/styles/globals.css)）。

### 3.8 辅助工具（跨窗口录入 / 剪贴板 / 置顶）

- **需求背景**：网文作者常需把文字录入其他平台（发文/存稿），需要系统级辅助能力且零原生依赖。
- **交互流程**：顶栏「工具 → 辅助工具」→ 跨窗口录入（当前章节/剪贴板、目标窗口标题、快/慢节奏）→ 点击开始后切到目标窗口 → 逐块粘贴；剪贴板监听开启后历史一键插入光标处；窗口置顶开关。
- **原型说明**：对应旧版 Python 工具能力在 Web 栈的重建；Coze 转写/随机生成标注 P2。
- **验收标准**：中文逐块（快 200字/0.5s、慢 100字/5s）粘贴不丢字；录入器自身写剪贴板不产生回环；全局热键 Ctrl+G 唤起主窗口。
- **实现状态**：✅ 已实现（[typer.ts](../desktop/src/main/services/typer.ts)、[clipboard.ts](../desktop/src/main/services/clipboard.ts)、[ToolsDialog.tsx](../desktop/src/renderer/src/components/ToolsDialog.tsx)）。

### 3.9 数据化收口（状态栏与统计）

- **需求背景**：状态栏此前为硬编码占位，需反映真实创作数据。
- **交互流程**：输入实时刷新「字数」；保存时按净增累计「今日」；目标进度条 + 百分比；「自动保存」显示最近保存时间。
- **验收标准**：今日净增 = 相对上次保存的字数增量（删除不产生负增长）；跨天自动重置；每日目标默认 2500 可持久化。
- **实现状态**：✅ 已实现（[StatusBar.tsx](../desktop/src/renderer/src/components/StatusBar.tsx)、[appStore.ts](../desktop/src/renderer/src/stores/appStore.ts)）。

| 状态栏 | 目标达成视觉 | 进度 ≥100% 进度条与百分比变绿 + 通知推送 |
| | 字数飞入动效 | 字数 / 今日增量更新时短暂飞入动画 |
| 引导 | FTUE 首次启动引导 | 3 步浮层（建作品 → 写作 → AI 润色），可跳过并持久化 |
| 安全 | 删除 / 清空对话二次确认 | ConfirmDialog 统一确认，防误操作 |
| 新建作品 | 完整向导 | 作品名 / 副标题 / 题材 / 篇幅 / 每日目标字数 / 简介 / 默认卷名 / 立即建第一章 |

### 3.11 全局全文搜索与历史版本（2026-08-14 P2 推进）

- **全局全文搜索（Ctrl+Shift+F）**：跨全部作品遍历检索章节正文分块与全部创作知识（纯本地 BM25，默认不启用 Embedding），结果按相关度合并排序并标注来源作品；章节结果一键切换到对应作品与章节，知识结果引导至侧栏对应 Tab。
- **历史版本管理**：`Ctrl+S` 手动保存时对当前章节生成 Markdown 快照（`works/<id>/versions/<seq>/<ts>.md`），每章保留最近 50 份；「文件 → 历史版本」弹窗列出快照（时间 / 字数 / 备注），点击预览、确认后恢复到编辑器并落盘。自动保存（防抖 800ms）不生成版本，避免快照爆炸。

### 3.12 多格式导出 / 插件机制 / SQLite 引擎（2026-08-14 第四轮）

- **多格式导出**：作品级导出扩展至 PDF / EPUB / DOCX —— PDF 经隐藏窗口渲染 HTML 后 `printToPDF`（A4、衬线排版）；EPUB 由 jszip 组装标准 EPUB3 结构（mimetype/container/opf/toc/章节 xhtml）；DOCX 由 docx 库生成（标题层级 / 列表 / 正文段）。菜单「文件 → 导出作品」六种格式可选。
- **插件机制（最小骨架）**：启动时扫描 `<data>/plugins/*.js`（CommonJS），插件导出 `name/version/description` 元数据与可选 `onStart(ctx)` 钩子；辅助工具面板展示已加载插件列表，加载失败仅告警不阻断。
- **SQLite 存储引擎**：新增 [store-sqlite.ts](../desktop/src/main/services/store-sqlite.ts)（sql.js wasm，零原生依赖），实现与文件版完全一致的 `IWorksStore` 接口 —— 作品/章节索引/创作知识/设置/版本索引入 `continuum.db`，正文与版本快照仍存 Markdown 文件。设置环境变量 `CONTINUUM_STORAGE=sqlite` 即切换，IPC 与渲染层零改动；单测覆盖 CRUD 与落盘重开持久化。

### 3.13 卷层级 / 编辑器标题块 / 伏笔联动（2026-08-14 第五轮）

- **卷容器（章节管理优化）**：作品 → 卷 → 章节三级层级。卷支持新增（`+ 卷`）/ 重命名（双击卷名或 hover ✎，与作品/章节同款弹窗式）/ 删除（二次确认，卷内章节保留为未分卷）/ 上移下移排序；章节通过行内「⋯ → 移至卷」下拉归属卷。未归属章节归入「未分卷」系统分组，**分组名可自定义**（双击分组弹窗重命名，按作品持久化于 `settings.json` 的 `unassignedLabel_<workId>` 键）。存储层强制**单归属约束**（同一章节只属于一个卷），删除章节时级联清理卷关联。数据落 `works/<id>/volumes.json`（SQLite 引擎落 `volumes` 表）。
- **编辑器标题块（初始化优化）**：加载章节时自动在正文开头插入「章节标题块」（Tiptap `chapterTitle` 节点，携带 `seq` 绑定），默认文本块可编辑；章节重命名时若标题块文本未被用户编辑则自动同步新名（保留原始绑定，支持后续批量同步扩展）。Markdown 往返后按「首块文本 === 章节名」重新绑定，持久可靠。
- **伏笔联动**：选区悬浮条新增「创建伏笔」——以选中原文为锚点（`Note.anchorText` + `chapterSeq`）创建伏笔并唯一绑定；正文中锚点文本以状态色 `foreshadow` 标记高亮（已埋设/进行中/已回收，颜色随 `tag` 状态变化）；点击标记 → 侧栏切换伏笔 Tab 并滚动定位对应卡片 + 1.8s 临时高亮；卡片「定位原文」→ 编辑器选中锚点选区并滚动（跨章节自动切换）；伏笔状态变更后标记颜色即时同步。

### 3.14 时间线模块（2026-08-14 第六轮）

- **时间线条目**：独立条目含可编辑「时间描述」输入框与「剧情梗概」文本框，支持新增（`+ 新建` → 输入时间）/ 内联编辑（失焦立即落盘 + 输入间隙 400ms 防抖，本地实时存储）/ 删除（二次确认）/ 上移下移排序。数据落 `works/<id>/timeline.json`（SQLite 引擎落 `timeline` 表）。
- **正文标注联动**：编辑器加载时扫描正文，将「时间线条目 time 文本」以紫色 `timeline` 标记高亮（带 `entryId` 与标题提示）；点击标注 → 侧栏自动展开并切换时间线 Tab → 滚动定位对应条目 + 1.8s 临时高亮；时间线增删改（尤其修改时间）后全文重建标注，正文标注与时间线数据实时同步。

### 3.15 大纲模块（2026-08-16 第八轮）

- **大纲工作台**：侧边栏「大纲」Tab 常驻入口 → 中央模式切换（写作 ⇄ 大纲，`uiStore.centralMode`）；三视图（大纲列表 / 章纲 / 思维导图）+ 粒度切换（仅核心节点 / 完整细纲）。大纲树节点含节奏标签（开篇/发展/高潮/转折/低谷/伏笔/结局）、预估字数、关联章节（点击跳转）、涉及角色（关联角色卡）；遵循 S4 交互职责分离（折叠图标独立 + 双击配对重命名）。
- **章纲管理**：每章一条（核心剧情 / 角色互动场景 / 关键冲突点 / 章末钩子 / 备注 / 写作状态），内联 400ms 防抖自动保存；删除章节级联清理。
- **思维导图**：零依赖 SVG 树状图（缩放/平移/增删改节点），三种模板（剧情线/人物关系/世界观），与大纲双向生成（大纲→导图快照 / 导图→大纲递归转换）；支持 XMind 大纲文本导入（Tab/空格缩进 + Markdown 列表/标题，深度跳变自动修正）。解析器共享于 `src/shared/mindmap-parse.ts`。
- **智能章纲提取（AI「提取」）**：范围（当前章节 / 最近 20 章 / 自定义 ≤50 章），主进程排队逐章调用 DeepSeek，每成功 1 章经 `AiQuotaService` 消耗 1 次配额（每日 100 次、跨天懒重置、AI 功能全局共享账本），失败/跳过不消耗；结果写入章纲（`extracted=true`）。
- **大纲挂载智能问答（AI「对话」）**：引用上下文（大纲节点 / 章纲 / 章节正文胶囊）+ 知识库来源「本书内容」（大纲+章纲+正文+创作知识，6000 字窗口截断）→ DeepSeek 流式问答，沿用透明 AI 注入徽标。
- 数据：`outline.json` / `chapter_outlines.json` / `mindmap.json`（SQLite 引擎落 `outline_nodes` / `chapter_outlines` / `mind_maps` 表），配额账本存 `settings.aiQuota`；IPC 43→56 通道。

### 4.5 可复用技术标准（M8 沉淀）

第五 / 六轮（卷层级、编辑器标题块、伏笔联动、时间线）沉淀出一套可复用的技术标准，后续新功能应遵循：

**S1 · 存储引擎双实现标准**：领域实体统一经 `IWorksStore` 接口读写。新增实体必须四步落地：
1. `shared/types.ts` 定义领域类型；
2. 文件版 [store.ts](../desktop/src/main/services/store.ts) 与 SQLite 版 [store-sqlite.ts](../desktop/src/main/services/store-sqlite.ts) **同步实现**（同签名、同语义），并实现父对象删除时的级联清理（如删章节清理卷关联、删作品清卷/时间线/知识/版本）；
3. preload 白名单分组 + 主进程 `ipcMain.handle` 同步注册；
4. 双引擎单测覆盖 CRUD / 排序 / 落盘重开持久化 / 级联清理。

**S2 · 编辑器内联标注与双向联动标准**（伏笔 `foreshadow` 标记、时间线 `timeline` 标记共用同一模式）：
- **Mark 扩展**：`parseHTML` 按 `data-*` 属性还原（id / 状态 / 时间），`renderHTML` 输出带属性、状态色 class 与标题提示的可点击标记；
- **文本锚点绑定**：以「原文文本」为锚（存于数据实体，如 `Note.anchorText`、`TimelineEntry.time`），加载 / 数据变化时 `findAnchorRanges` 全文扫描，先 `removeMark` 再 `addMark` **全文重建**——天然支持增删改后的标注自动同步；
- **装饰性事务守卫**：标注重建属装饰性变更（不改变正文文本），经 `applyingMarks` 标志在 `onUpdate` 中跳过保存 / 统计逻辑，避免无谓落盘；
- **双向定位**：标记点击 → 全局 `uiStore` 聚焦信号 `{ id, ts }`（时间戳触发 effect）→ 侧栏滚动定位 + 1.8s 临时高亮；侧栏收起时自动展开；反向由侧栏「定位」动作经 store 信号驱动编辑器选区 + `scrollIntoView`；
- **状态同步**：数据变更（编辑 / 删除）→ store 更新 → 编辑器重建标记，两端一致。

**S3 · 章节标题块绑定标准**：自定义块节点携带绑定键（`chapterTitle.seq`）；「重命名同步」仅在标题块文本仍等于旧标题（未被用户编辑）时生效，尊重创作编辑；Markdown 往返后按「首块文本 === 章节名」重绑兜底，保证持久可靠。

**S4 · 交互职责分离标准**：同一行元素同时具备「展开/折叠」与「双击编辑」两类交互时，将两者**按元素分离**——展开/折叠独立为行首「折叠图标」按钮（`stopPropagation`，单击立即生效），行体仅承载「双击重命名」（300ms 内点击配对检测，不依赖浏览器原生 dblclick 事件；原生 `onDoubleClick` 作兜底）。避免单击与双击抢用同一元素导致的浏览器双击判定丢失（卷行重命名问题的根治方案）。

**S5 · 测试标准**：存储层双引擎 CRUD；纯决策 / 检索函数直接单测（如 `chapterTitleAction`、`findAnchorRanges`）；UI 交互用 RTL + jsdom 驱动 store 与事件流（增删改 / 排序 / 聚焦高亮 / 收起态）；全量验证 = `typecheck` + `npm test` + `npm run build` + dev 启动冒烟。

## 7. AI 适配层与混合 RAG 设计

### 7.1 OpenAI 兼容适配层（[openaiCompat.ts](../desktop/src/renderer/src/lib/ai/openaiCompat.ts)）

- 端点：`<baseUrl>/chat/completions`，`stream: true`（SSE）；
- 逐行解析 `data:` 增量，`[DONE]` 结束；增量经 `onDelta` 回调实时渲染，支持 `AbortSignal` 中断；
- 错误分层：缺 Key（非本地服务）→ `AIError`；HTTP 非 200 → 携带 `status`；网络/流中断 → 明确提示；
- 内置 Provider 预设：DeepSeek / OpenAI / 硅基流动 / Ollama（本地免 Key）；
- 配置持久化于 `settings.json` 的 `ai` 键（复用 settings IPC）。

### 7.2 混合检索（[search-core.ts](../desktop/src/main/services/search-core.ts) / [search.ts](../desktop/src/main/services/search.ts)）

**语料范围**（用户确认）：章节正文（按 500 字块切分、50 字重叠）+ 全部创作知识实体（角色/设定/伏笔/素材）。

**本地 BM25**：

- 分词：中文单字 + 相邻二字 n-gram + 英文/数字词（`[a-z0-9]+`）；
- 打分：`BM25(k1=1.5, b=0.75)`，IDF 平滑 `log((n-df+0.5)/(df+0.5)+1)`；
- 长文本 `chunkText` 切块，重叠窗口保证跨块上下文召回。

**远程 Embedding（可选增强）**：

- 端点：`<baseUrl>/embeddings`，批量编码，按 `index` 排序返回；
- 缓存：`works/<id>/embeddings.json` 按 chunk 文本指纹失效，仅正文/知识变化时重建；
- 超时 60s，失败静默降级纯本地。

**融合策略**：BM25 归一化分数 × 0.5 + 余弦相似度 × 0.5 → `score ∈ [0,100]`；命中输出「来源标签 + 标题 + 前 120 字片段」。

### 7.3 对话知识注入（[retrieval.ts](../desktop/src/renderer/src/lib/retrieval.ts)）

- AI 面板「对话」页勾选「注入知识库」（默认开启）；
- `sendChat(text, withContext, withKnowledge)`：以用户输入（截断 200 字）检索当前作品，命中 ≤5 条；
- 注入格式追加至系统提示词：

```
【作品知识库参考片段（回答时可参考，不必逐条引用）】
- [角色] 顾青舟：冷峻剑客，左肩有旧伤
- [设定] 北境：常年积雪，剑冢所在
- [章节] 第三章：顾青舟在剑冢拔剑
```

- 检索失败/未命中静默跳过，不阻塞对话。
