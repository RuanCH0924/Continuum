| 维度 | 指标 | 目标值 | 设计阶段预评 | 说明 |
| --- | --- | --- | --- | --- |

| | 组件复用率 | ≥ 80% | ⚠️ 预评达标 | 规范 §6 组件库收敛 6 类 20+ 组件；开发时以实例统计复验 |
| | 视觉走查通过率 | ≥ 95% | ✅ 规范可执行 | 走查清单来自设计规范 §6–§10 |
| 核心功能操作 | 全流程完成率 ≥ 98% / ≤ 15 步 | ✅ | 主链路 8 步（新建→码字→润色→导出） | 待用户测试实测 |
| 用户体验 | SUS ≥ 80 / NPS ≥ 50 / CSAT ≥ 4.5 | ⏳ | 需 P1 实现后用户测试 | 属实现阶段指标 |
| 多端适配 | 分辨率通过率 ≥ 99% / 高 DPI 100% | ⏳ | 设计规范 §9 已定策略 | 需开发后矩阵测试 |
| 无障碍 | WCAG 2.1 AA ≥ 95% / 键盘可达 100% | ⚠️ 设计已内置 | 设计规范 §10 六条 a11y 规范 | 需 axe-core 扫描复验 |
| 性能 | TTI ≤ 1.5s / 输入 ≤ 50ms / 首字 ≤ 800ms | ⏳ | 设计轻量化（无重资源） | 开发后打点 |
| 稳定性 | UI 崩溃 ≤ 0.1% / 视觉回归 ≤ 2% | ⏳ | — | 开发后监控 |
