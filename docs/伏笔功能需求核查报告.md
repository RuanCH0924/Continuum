## 2. 核查发现的缺陷与整改

### 缺陷 1（高）：SQLite 存储层丢失伏笔锚点

- **现象**：`store-sqlite.ts` 的 `notes` 表无 `anchor_text` 列，`saveNote/listNotes` 均未持久化 `anchorText`。
- **影响**：SQLite 模式下伏笔「锚点绑定 / 双向定位」完全失效，且正文标记无法重建，违背双引擎一致性标准。
- **整改**：`migrate()` 幂等增量迁移 `notes` 表（`anchor_text` / `anchor_offset` / `archived` / `archived_at`），`saveNote/listNotes` 完整读写新字段。旧库打开时自动升级，无需手工迁移。
- **验证**：新增 `store-sqlite.test.ts`「伏笔锚点持久化：落盘重开保留」。

### 缺陷 2（中）：伏笔删除无二次确认

- **现象**：`NoteEditorDialog` 的「删除」直接执行删除，不满足 §3.3 验收标准「删除确认」。
- **整改**：对话框删除先弹 `ConfirmDialog`（提示正文标记同步清除 + 日志留存）；侧栏批量删除同样二次确认。
- **验证**：新增 `clue-archive.test.tsx` 批量删除确认交互测试。

### 缺陷 3（中）：同文锚点多处出现时关联可能错位

- **现象**：`applyForeshadowMarks` 对同文本所有出现位置打标，多个伏笔共用同一锚点文本时标记归属不确定。
- **整改**：创建时记录选区在章节纯文本中的起始偏移 `anchorOffset`；重建 / 定位时按「距创建偏移最近」消歧（`findClueAnchorRange`）；锚点已被修改/删除时返回 null 并给出实时校验提示。
- **验证**：新增 m8 测试「findClueAnchorRange：同文多出现时按创建偏移消歧」。

### 缺陷 4（低）：创建页 ↔ 编辑页缺乏双向跳转

- **现象**：伏笔创建入口（对话框）与正文编辑器之间无主动跳转能力，关联校验依赖隐式重建。
- **整改**：见 §3 需求 2。

## 3. 五项任务整改说明

### 任务 1：功能覆盖率核查

本报告即核查交付物。已对照需求基线逐一验证：四项缺陷全部整改并补齐回归测试，未发现其他未达标项。

### 任务 2：伏笔创建页面与编辑页双向合规跳转 + 精准关联

- **创建页 → 编辑页**：对话框新增「定位到正文 →」按钮（`jumpToChapter`）：选择 / 绑定关联章节后跳转编辑器，含锚点时自动选中并滚动；选区创建伏笔保存后自动 `locateClue` 定位并校验锚点（成功即选中闪烁，失效即提示）。
- **编辑页 → 创建页**：编辑器选区「创建伏笔」→ 对话框（原能力保留）；正文标记点击 → 侧栏伏笔卡片（原能力保留）。
- **合规**：关联章节由数字输入改为下拉选择（仅合法章节号），杜绝无效关联。
- **精准关联 / 可追溯 / 可实时校验**：`anchorOffset` 记录创建位置 → 消歧；删除日志留存锚点快照；`findClueAnchorRange` 实时校验锚点有效性。

### 任务 3：伏笔删除联动 + 删除日志

- **批量删除**：`NotesDeleteBatch` IPC → `store.deleteNotes`（双引擎）；侧栏多选 + 二次确认；编辑器标记随 notes 变更自动重建清除（装饰性标记不落盘，无残留风险）。
- **删除日志**：删除前为每个被删条目留存完整数据快照（含锚点 / 章节 / 归档状态）至 `notes_delete_log.json`（SQLite 为 `note_delete_logs` 表），`notes.deleteLogs` 可检索（按删除时间倒序）。
- **一致性**：删除 / 归档后 `loadNotes + loadArchivedNotes` 双列表刷新，活跃列表、归档池、正文标记、RAG 语料四端同步。

### 任务 4：伏笔归档模块

- 伏笔卡片新增「归档」操作与批量归档；归档项移入独立归档池（`archived=true` + `archivedAt`），保留完整原始数据（含锚点，可「定位原文」回溯）。
- 归档伏笔不再出现在活跃列表 / 正文标记 / RAG 检索语料；支持单条 / 批量「恢复」回活跃列表。
- 归档池按归档时间倒序展示，支持关键词检索（复用侧栏搜索框）。

### 任务 5：素材归档（统一归档池）

- 素材列表同步支持「归档」与批量归档；归档池统一承载伏笔 + 素材，支持「全部 / 伏笔 / 素材」内容类型筛选与归档时间维度展示；恢复 / 删除交互与伏笔完全一致。
